# Weekly Google Search Console checklist for a small business website (25 minutes)

Search Console is Google's first-party data on your site. Use it weekly, not only after traffic drops.

- **Performance**: read clicks, impressions, CTR and average position together. High impressions with weak CTR usually means the title and snippet are losing the click.
- **Pages first**: filter by page and review service, city and pricing pages before blog posts.
- **Queries**: list queries where you already appear and no page answers them well. Each is a content brief.
- **Page indexing**: before blaming content, check the page is indexed, and read the reason if it is not.
- **Sitemaps**: after publishing, confirm the sitemap was read and the new URL is in it.
- **Core Web Vitals**: use the mobile report to decide which template to fix first.
- **CTR wins**: a page at position 5.8 with 8,400 impressions and a 1.1% CTR can nearly double its clicks with a clearer title, with no ranking change.

Keep a one-page log: date, what you saw, what you changed.
